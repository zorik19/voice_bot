
# Voicebot — голосовой AI-продавец ОСАГО (MVP)

Пайплайн: микрофон → silero-vad → faster-whisper → GigaChat (function calling) → Silero TTS → колонки. Все провайдеры за интерфейсами — GigaChat меняется на Claude, Silero на SpeechKit одной строкой в `.env`.

Дефолтный контур — **полностью российский/локальный**: GigaChat + whisper + Silero. Ни VPN, ни зарубежных карт.

## Установка (пошагово, без опыта программирования)

Код кроссплатформенный (проверено), но команды установки отличаются — выберите свою систему.

### macOS

Понадобится приложение **Terminal** (Программы → Утилиты → Terminal) — команды ниже копируются туда целиком и запускаются по Enter.

**1. Установить Python 3.11**, если его ещё нет.
Проверить, есть ли он:
```bash
python3.11 --version
```
Если пишет "command not found" — скачать установщик с [python.org/downloads](https://www.python.org/downloads/release/python-3119/) (нужна версия 3.11.x) и установить как обычное приложение.

**2. Скачать код проекта.**
На странице репозитория на GitHub нажать зелёную кнопку **Code → Download ZIP**, разархивировать (двойной клик по скачанному файлу) и перетащить папку `voicebot` куда удобно, например в `Документы`.

**3. Перейти в папку проекта в Terminal.**
Проще всего: в Terminal набрать `cd ` (с пробелом в конце), затем перетащить папку `voicebot` из Finder прямо в окно Terminal — путь подставится сам — и нажать Enter.

**4. Создать изолированное окружение и поставить зависимости:**
```bash
python3.11 -m venv .venv
source .venv/bin/activate
pip install -e .
```
Эти три команды нужно ввести по очереди, дожидаясь, пока предыдущая закончится. Установка займёт несколько минут (скачивает модели распознавания речи).

**5. Получить ключи доступа (`.env`).**
Файл `.env` с настоящими ключами вам должны прислать отдельно (например, по почте) — в git его нет специально, это как пароль. Когда получите файл `.env`, положите его прямо в папку `voicebot` (туда же, где лежит файл `.env.example`), рядом с `config.py`.

**6. Запустить текстовое демо** (печатаете реплики клиента с клавиатуры, бот отвечает текстом — без микрофона и колонок):
```bash
python -m demos.demo_kasko_proactive --no-tts
```
Бот напечатает приветствие и предложение `👤 Клиент:` — вводите ответ и жмите Enter. Чтобы закончить: написать `выход` или нажать Ctrl+C.

Каждый раз, открывая новый Terminal для работы с проектом, сначала нужно снова перейти в папку проекта (шаг 3) и выполнить `source .venv/bin/activate` — иначе Python не найдёт установленные зависимости.

### Windows

Понадобится **PowerShell** (найти через Пуск → набрать "PowerShell" → открыть обычный, не "Admin").

**1. Установить Python 3.11**, если его ещё нет.
Проверить:
```powershell
python --version
```
Если не найден или версия другая — скачать установщик с [python.org/downloads](https://www.python.org/downloads/release/python-3119/) (версия 3.11.x, файл вида `python-3.11.9-amd64.exe`). **Важно** на первом экране установщика поставить галочку **"Add python.exe to PATH"** внизу окна, потом Install Now.

**2. Скачать код проекта.**
На странице репозитория на GitHub нажать зелёную кнопку **Code → Download ZIP**. В папке `Загрузки` кликнуть правой кнопкой по скачанному файлу → **Извлечь всё** (Extract All), затем переместить извлечённую папку `voicebot`, например, в `Документы`.

**3. Перейти в папку проекта в PowerShell.**
В открытой папке `voicebot` в Проводнике кликнуть по адресной строке сверху, ввести `powershell` и нажать Enter — PowerShell откроется сразу в этой папке.

**4. Создать изолированное окружение и поставить зависимости:**
```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -e .
```
Если вторая команда выдаёт ошибку про "выполнение скриптов отключено" (execution policy) — выполнить один раз:
```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
```
и повторить `.venv\Scripts\Activate.ps1`. Установка `pip install -e .` займёт несколько минут (скачивает модели распознавания речи).

**5. Получить ключи доступа (`.env`).**
Файл `.env` с настоящими ключами вам должны прислать отдельно (например, по почте) — в git его нет специально, это как пароль. Когда получите файл `.env`, положите его прямо в папку `voicebot` (туда же, где лежит файл `.env.example`), рядом с `config.py`. В Проводнике по умолчанию скрыты расширения файлов — убедитесь, что файл называется ровно `.env`, а не `.env.txt` (Вид → Расширения имён файлов, чтобы проверить).

**6. Запустить текстовое демо** (печатаете реплики клиента с клавиатуры, бот отвечает текстом — без микрофона и колонок):
```powershell
python -m demos.demo_kasko_proactive --no-tts
```
Бот напечатает приветствие и предложение `👤 Клиент:` — вводите ответ и жмите Enter. Чтобы закончить: написать `выход` или нажать Ctrl+C.

Каждый раз, открывая новый PowerShell для работы с проектом, сначала нужно снова перейти в папку проекта (шаг 3) и выполнить `.venv\Scripts\Activate.ps1` — иначе Python не найдёт установленные зависимости.

### Другие варианты запуска (когда основы уже работают)

```bash
# Текстовое демо + озвучка ответа бота (без --no-tts)
python -m demos.demo_kasko_proactive

# Обычное демо (не КАСКО-сценарий)
python -m demos.demo_text

# Полное голосовое демо (в наушниках!) — микрофон, фоновый шум, barge-in
python -m demos.demo_voice

# То же самое, но сценарий "посчитал КАСКО и не оплатил"
python -m demos.demo_voice_kasko_proactive
```

Первый запуск скачает модели: whisper small (~460 МБ, HuggingFace) и silero tts/vad (~60 МБ, серверы Silero, доступны из РФ). Дальше всё работает офлайн, кроме LLM.

Ключ GigaChat — единственный обязательный: ЛК developers.sber.ru → проект GigaChat API → Authorization key (это он, длинный base64; сам обменивается на access token внутри SDK). Scope: GIGACHAT_API_PERS для физлица (freemium-токены), CORP/B2B для юрлица. TTS ElevenLabs для wow-демо: вписать ключ и `VOICEBOT_TTS_PROVIDER=elevenlabs`.

## Структура

```
config.py            все настройки и пороги (env-переменные VOICEBOT_*)
factory.py           сборка провайдеров по конфигу
orchestrator.py      FSM звонка, barge-in, sentence-streaming в TTS, tool loop
core/                типы, интерфейсы (Protocol), JSONL-логгер звонков
audio/vad.py         StreamingVAD (конец фразы) + BargeInDetector (жёсткие пороги)
audio/io.py          микрофон/колонки (sounddevice) + ресемплинг
providers/stt|llm|tts  whisper, claude, silero, elevenlabs + заглушки yandex/gigachat
domain/osago.py      калькулятор ТБ×КТ×КБМ×КВС×КМ + схема тула
domain/kasko_offer.py  модель данных проактивного обзвона: расчёт клиента,
                        оптимальные условия по модели, таблица альтернатив
prompts/seller.py    системный промпт Анны, приветствие, переспросы
prompts/kasko_proactive.py  сценарий "посчитал КАСКО и не оплатил" (шаги 1-8,
                             продажа по готовым данным, лимит 2 альтернативы)
demos/               demo_text (текст→голос), demo_voice (полный пайплайн),
                      demo_kasko_proactive (проактивный обзвон, см. ниже)
logs/                JSONL по каждому звонку: реплики, тайминги, tool calls
```

## Сценарий "посчитал КАСКО и не оплатил"

`demos/demo_kasko_proactive.py` + `prompts/kasko_proactive.py` + `knowledge/kasko_proactive.yaml`.

Бот проактивно звонит клиенту, который сам посчитал КАСКО на сайте и не
оплатил. В отличие от `prompts/kasko_callback.py` (старый скрипт-дожим, прячет
цифры за "предложение на почте"), этот сценарий сразу оперирует реальными
цифрами клиента и ведёт разговор по шагам: верификация → проверка
актуальности → презентация текущего расчёта и, если выгоднее, оптимального
варианта по модели → подбор альтернативы из готовой ценовой таблицы (не
больше двух попыток за звонок) → если не продалось — сбор скана прошлого
полиса для будущей скидки → тёплое завершение в любом исходе.

Данные клиента — `domain/kasko_offer.ClientOffer`: текущий расчёт (2.1),
оптимальные условия по модели (2.2) и таблица уже посчитанных альтернативных
цен (2.3), как их отдаёт внутренний API. `sample_offer()` — фикстура для
демо; `load_offer_from_api()` — разбор реального ответа (топ-level конверт
уточняется при интеграции). Внутренняя аналитика альтернатив (conversion,
netIncome, ccu, частота/тяжесть убытков) в промпт не попадает — бот видит
только цены.

База знаний `knowledge/kasko_proactive.yaml` — черновик, формулировки нужно
сверить с командой поддержки (см. комментарий в файле).

## Как устроена задержка

Между «клиент замолчал» и «бот заговорил»:
VAD-финализация (~settings.vad_silence_ms, 700мс) → whisper small (~300-600мс на M2) → first token Claude (~400мс) → первое предложение сразу в TTS, не дожидаясь остального ответа. Тайминги каждого этапа пишутся в лог (`stt.latency_ms`, `first_sentence.latency_ms`) — смотри их, прежде чем крутить пороги.

## Barge-in

Пока бот говорит, входящий поток слушает `BargeInDetector` с порогами жёстче обычного VAD (защита от эха/самоперебивания). Сработал — отмена response-таски (asyncio cancel), мгновенный сброс очереди воспроизведения, в историю пишется фактически сказанная часть с пометкой `[клиент перебил]`, чтобы LLM не считал реплику договорённой.

## Профили аудио

`VOICEBOT_AUDIO_PROFILE=phone` ужесточает пороги VAD/barge-in под шумный телефонный канал 8kHz. Ресемплинг 8k↔16k уже есть в `audio/io.py` — телефонный транспорт (Asterisk AudioSocket) реализует тот же интерфейс `AudioTransport`, оркестратор не меняется.

## План до продакшена

1. **Закрытый контур**: GigaChat уже подключён (для прода — on-prem инстанс + сертификат НУЦ Минцифры вместо verify_ssl_certs=False); `providers/stt|tts/yandex.py` (gRPC streaming v3, натренирован на телефонии) — заглушки с планом уже в файлах.
2. **Телефония**: Asterisk + AudioSocket-транспорт (TCP-фрейминг, аналогично Shelter) + SIP-оператор (Exolve/Zadarma), или их media API.
3. **STT-стриминг**: SpeechKit даёт partial-транскрипты — можно начинать думать до конца фразы клиента.
4. **Масштабирование**: оркестратор per-call, statless-провайдеры общие; очередь звонков через RabbitMQ (паттерн aiuw подходит).

## Примерная стоимость на звонок (~3 мин)

| Компонент | Демо | Прод |
|---|---|---|
| LLM | GigaChat freemium — бесплатно | GigaChat B2B / on-prem |
| STT | whisper — бесплатно | SpeechKit ~0.5 ₽/15с распознавания |
| TTS | Silero — бесплатно | SpeechKit ~1 ₽/1000 симв. |
| Телефония | — | ~1.5-2 ₽/мин (исходящий, моб. РФ) |

Итого прод-звонок в облачном варианте — порядка 10-20 ₽; on-prem (GigaChat + локальные STT/TTS на GPU-сервере) — только телефония и железо.
